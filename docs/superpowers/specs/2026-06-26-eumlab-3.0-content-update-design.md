# EUMLab 3.0 — Systematic Content Update (Design Spec)

**Date:** 2026-06-26
**Branch:** 3.0
**Scope:** Homepage content/data, navigation, footer, and a new in-site Support (Contact Us) page.

## Goal

Trim the homepage to the content that still matters, refresh the download
figure, simplify navigation by removing Blog/Jobs, bring Support in-site as a
simple contact page, and unify the contact email.

## Decisions (confirmed with user)

- "删除 Ukulele / Behind the Screen 页面" = remove the two **fullPage scroll
  sections** on the homepage (`#sec-uke`, `#sec-press`). Individual app landing
  pages (iUke, UkeChords, …) stay.
- `/jobs/` page is **kept but unlinked** — remove every link to it; do not edit
  the page file.
- Support page = **simple Contact Us page, email only** (no form).
- Download figure display text = **"150 million"**.
- Footer keeps **both** Contact and Support links (Contact = mailto, Support =
  in-site page).

## Changes

### 1. Homepage desktop — `src/pages/index.astro`

The page is a fullPage.js vertical scroll: `intro → ukulele → figure → press`.

1. **Remove the `ukulele` section** — the entire `<div id="sec-uke" …>` block
   ("We specialize in ukulele apps" + uke app icon switcher). Remove the now
   unused `ukeApps` / `ukeAppsReversed` imports/locals.
2. **Remove the `press` section** — the entire `<div id="sec-press" …>` block
   ("Behind the screen, backed by the best team" Berlin/Hangzhou + "And we are
   still hiring!" link). This block currently contains the footer.
3. **Relocate the footer** — move `<Footer />` into the now-last `figure`
   section (`#sec-figure`), wrapped in a footer container positioned at the
   bottom of the screen (mirroring the original `.press-footer` absolute
   positioning). Keep the `<Footer />` component import.
4. **Update the download number** — in `#sec-figure`:
   `With <em>5,300,000</em> downloads,` → `With <em>150 million</em> downloads,`
   (rest of the line unchanged: "musicians get inspired by our apps").
5. Final fullpage flow: `intro → figure` (figure now carries the footer).

### 2. Homepage mobile — `src/pages/m/index.astro`

Already has only `intro` + `figure` (no uke/press sections, no footer).

- Change `<em>4,500,000</em> musicians get inspired by our apps` →
  `<em>150 million</em> downloads — musicians get inspired by our apps`
  (re-framed to read as a download count, matching desktop). Keep the
  "And they ♥ them…" subline and reviews unchanged.

### 3. Homepage JS — `public/assets/scripts/home2.js`

- **Critical:** `var pages = ['intro', 'ukulele','figure','press'];` →
  `var pages = ['intro', 'figure'];` (drives fullPage anchors/body classes).
- Remove now-dead code referencing deleted sections:
  - `resizeForUke()` function + its call in `setAppsPosition()`.
  - `resizeForPress()` function + its call in `setAppsPosition()`.
  - The `#ukeapp-icons-container li a` click handler.
- Keep: intro animations, `setAppsPosition`, `resizeForFigures`, `changeQuos`
  (figure review rotation), `heartBeat`, preloader, `checkScreenSize`.

### 4. Navigation — `src/components/Nav.astro`

Current items: Support (external) · Jobs · Blog · About · Products.

- Remove `<li id="menu-item-jobs">` (Jobs).
- Remove `<li id="menu-item-team">` (Blog → `blog.eumlab.com`).
- Change Support: `<a href="http://support.eumlab.com" target="_blank"
  rel="nofollow">` → `<a href="/support/">`.
- Final items: Support · About · Products.

### 5. New Support page — `src/pages/support/index.astro`

- New route `/support/`. Uses `Base` layout + `Nav` (with `appsMenu`) +
  `Footer`, consistent with `about`/`imprint`.
- Content: a "Contact Us" heading, one short line of helper text, and
  `support@eumlab.com` rendered as a `mailto:support@eumlab.com` link. No form.
- Style: reuse the simplest existing page style hook (e.g. the same base style
  as `imprint`/`about`) so it visually matches the site. A small amount of
  scoped CSS in the page is acceptable; do not introduce a new global
  stylesheet unless an existing one fits cleanly.
- `<title>` / meta: appropriate "Support - EUMLab" title.

### 6. Footer — `src/components/Footer.astro`

Current items: About · Jobs · Blog · Imprint · Contact · Support.

- Remove **Jobs** link.
- Remove **Blog** link.
- **Contact**: `mailto:team+web@eumlab.com?subject=Hi` →
  `mailto:support@eumlab.com?subject=Hi`.
- **Support**: `http://support.eumlab.com` → `/support/`.
- Final items: About · Imprint · Contact · Support. Social icons + copyright
  unchanged.

### 7. `/jobs/` page — no change

Keep `src/pages/jobs/index.astro` reachable; do not edit. All inbound links
removed via the changes above (nav, footer, homepage hiring block).

## Out of scope (explicitly not changed)

- `src/pages/about/index.astro` — "5.3 million" figure and `press@eumlab.com`.
- `src/pages/pro-metronome/**` — "3 million" figures.
- `src/pages/jobs/index.astro` — "4.5 million", `hiring@eumlab.com`, Blog
  mention (page is unlinked, left as-is).
- `src/pages/404.astro` — its `support.eumlab.com` link is inside a
  commented-out block (not rendered); no change.

## Verification

- The `verify/` screenshot-diff harness checks fidelity vs. the **original**
  site. Homepage, nav, and footer now **intentionally** diverge, so those diffs
  are expected — do not treat them as regressions.
- Instead: `npm run build` succeeds; dev-server/preview render of `/` (desktop
  + `/m/` mobile) and `/support/` look correct — footer present and positioned
  on the homepage figure section, "150 million" shown, nav has no Blog/Jobs,
  Support links resolve in-site, no JS console errors from removed sections.

## Risks / notes

- Footer contrast on the figure section's light-blue background: dark footer
  text should read fine (same dark text the original press footer used). Verify
  visually; add a minor text-shadow/contrast tweak only if needed.
- fullPage.js with two sections: confirm anchors `#intro` / `#figure` and the
  right-side navigation dots render correctly after the `pages` array change.
